GORKHA ORIGINS — STATIC WEBSITE DEMO

Files:
- index.html: Main one-page website
- style.css: Responsive design and styling
- script.js: Mobile navigation and current year

PREVIEW LOCALLY:
1. Extract the ZIP file.
2. Open the gorkha-origins-demo folder.
3. Double-click index.html to open it in your browser.
4. An internet connection is needed for Google Fonts and the sample Unsplash photos.

BEFORE PUBLISHING:
- Replace hello@gorkhaorigins.com if you use another email.
- Add your real Instagram URL and business address.
- Replace sample photography with your own product and producer photos.
- Confirm the products and descriptions match what you actually sell.
- The contact button currently opens the visitor's email app; there is no database or online order system.

DEPLOYMENT:
This is a static HTML/CSS/JS site and can be deployed to Cloudflare Pages. For a simple upload, use the folder containing index.html, style.css and script.js as the site output directory. No build command is required.
